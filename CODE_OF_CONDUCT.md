# Code of Conduct

This project follows the Contributor Covenant expectations in plain language:
be respectful, assume good faith, and keep collaboration focused on the work.

Unacceptable behavior includes harassment, hate speech, doxxing, sexualized
attention, and repeated disruption after maintainers ask for a change.

Report issues to the maintainer listed in `SECURITY.md`. Maintainers may remove
content, block participants, or close threads to protect the project.
